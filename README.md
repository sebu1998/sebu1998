### 🚀 What I'm building

> Most repos are private (employer work and own products). Code walkthrough on request. Every project keeps documented decisions and a test suite.

**🕐 Stundenheld** · *Swift · SwiftUI · SwiftData · CloudKit · macOS + iOS*<br>
Time tracking I use every single day: punch clock, projects, daily and weekly targets, statistics, iCloud sync. One Xcode project, two apps, one shared core. 184 tests, in daily use since July 2026. Replaced my earlier Laravel web version.

**💰 klar.** · *Swift · SwiftUI · SwiftData · CloudKit*<br>
Local-first iOS finance app: multiple accounts, line-item receipts, on-device OCR scanning, CSV bank import, four subscription types, honest month-end forecast. No servers, no tracking. ~150 tests, TestFlight beta prepared.

**📡 KuRD-GNSS** · *React · TypeScript · GNSS/RTK · iOS + Android*<br>
Surveying app for cable and pipeline construction. Field crews measure house connections and mains to the centimetre and generate the as-built sketch directly on the phone. Two GNSS receivers integrated without vendor documentation, accuracy verified in the field at 2.0 cm horizontal and 1.1 cm vertical. 4,600+ automated tests. Rolling out to field crews now.

**📐 Digital Site Survey** · *React 19 · TanStack · Dexie/IndexedDB · Hono · SQLite*<br>
Offline-first tablet app that replaces the Excel and Word workflow for construction surveys. Site managers capture points and sections once, the app computes quantities, final survey and fitting weights. In production since May 2026.

**🔒 PII Redactor** · *Python · Presidio · spaCy · PyMuPDF*<br>
CLI that strips personal data (names, companies, IBANs, German ID numbers) from documents before they go into cloud AI tools. The reverse mapping never leaves the machine. 300+ tests.

Also on the bench: a GraphQL backend in .NET 10 / HotChocolate for a legacy WPF + SQL Server suite, a self-hosted VPS platform with a deploy pipeline per stack, an offline voice-memo transcriber in Swift, and a SwiftUI habit tracker.

### ⚙️ How I work

- **I run what I build.** Production deployments on VMs and small servers: HTTPS via Caddy, firewall, VPN access, monitoring, scheduled backups. Self-hosted first, no vendor lock-in.
- **Decisions get documented.** Every project keeps ADRs (what, why, which alternative I rejected) in a markdown second brain that doubles as my issue tracker.
- **AI as a tool, not a crutch.** Claude and Codex for reviews, architecture sparring and routine refactors, with hooks that block access to secrets and databases. The decisions stay mine.
- **I know the other side of the screen.** I've been the site foreman who had to use bad software in the rain. That's why my apps get tested on real construction sites before anyone calls them done.
