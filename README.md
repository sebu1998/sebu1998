### How I work

- **I run what I build.** My own VPS hosts seven services in Docker: one Postgres, GitHub Actions deploys with a dedicated key per stack, monitoring, daily backups. Self-hosted first, no vendor lock-in.
- **Decisions get written down.** Every project keeps ADRs: what, why, which alternative I rejected. My markdown vault doubles as the issue tracker.
- **AI as a tool, not a crutch.** Claude and Codex for reviews, architecture sparring and routine work, with hooks that block access to secrets and databases. The decisions stay mine.
- **I know the other side of the screen.** I was the foreman who had to use bad software in the rain. My apps get tested on real construction sites first.
